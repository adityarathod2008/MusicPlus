## 🚀 About MusicPlus

**MusicPlus** is a modern, full-featured music streaming platform built to deliver an exceptional audio experience. It comes equipped with a sleek user interface and robust backend capabilities, providing seamless access to a vast library of tracks. 

Whether you want to listen in your browser or through the dedicated desktop application, MusicPlus offers high performance and a beautiful aesthetic.

---

## ✨ Features
- **Cross-Platform**: Accessible via Web (Responsive HTML/JS) and Desktop (Python).
- **Sleek UI**: Modern design featuring smooth transitions and dark mode aesthetics.
- **Robust Backend**: Fast API handling audio streams and search queries.
- **Seamless Playback**: Uninterrupted audio streaming with custom controls.

## 💻 Installation & Usage

### Running the Web Version
1. Clone this repository.
2. Open `music_app.html` in your favorite modern browser.

### Running the Desktop App
1. Ensure Python 3 is installed.
2. Run `desktop_app.py` or use the provided executable scripts (`start_app.bat` / `build_app.bat`).
